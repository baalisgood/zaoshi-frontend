# Bundled assets

`public/` contains only assets used by the product UI: login-room illustration, style-preview illustrations, favicon/share images, provider/payment icons and standard SVG illustrations. No runtime user-upload directory or user object store is included.

The earlier frontend mock replaced product imagery with `public/demo/scene.svg`; that obsolete mock asset is removed as part of publishing the complete application source. Existing product image references now resolve to the bundled product files.
